Alert sounds for the cockpit speaker (Node 1). Generated by tools/make_sounds.py (original sounds).
  hello.wav    - played once when the cockpit starts ("system online")
  warning.wav  - WARNING (eyes closing)          - repeats while the state lasts
  slowing.wav  - SPEED_REDUCTION                  - repeats
  stop.wav     - CONTROLLED_STOP / EMERGENCY_STOP - repeats
To use your own sound: replace the file, keeping the same name. A missing file falls back to the built-in beep.
Any PCM WAV works (mono/stereo, any sample rate). MP3 -> WAV:  ffmpeg -i my.mp3 -ac 1 -ar 22050 warning.wav
